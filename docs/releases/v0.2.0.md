# RanD v0.2.0

## 概要

KanoMode を追加したリリースです。KanoMode は狩野モデルそのものではなく、ネット上の不満、称賛、比較、期待などの証跡から品質分類を仮説化し、要件定義向け artifact を生成するモードです。通常の research runtime に、Discovery mode と、既存要件定義を監査する Audit mode を追加しました。

特に一元的品質は、正式調査ではなく、競合比較や改善要求などのネット証跡を介して疑似的に再現する `performance` 仮分類として扱います。

## 含まれる内容

- KanoMode Discovery mode
  - `kano_requirements_hybrid`
  - `kano_requirements_offline_eval`
  - `kano.json`
  - `requirements_packet.json`
- KanoMode Audit mode
  - `kano_requirements_audit`
  - `requirements_audit_packet.json`
  - Requirement Definition Gate の `go / conditional_go / no_go` 判定
- state 保存の atomic write 対応
- `README`, `research-runtime/README.md`, `RUNBOOK`, KanoMode 要件・仕様・引継ぎ資料の更新
